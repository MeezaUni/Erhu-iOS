Erhu's first published sideloading beta for iPhone. Bring your own music files; no Erhu account
or music subscription is required.

### Choose a build

- **Static:** the player, VYBE, library tools, and still artwork.
- **Animated:** the same shared features plus motion-cover lookup, downloads, and playback.

Both builds require **iOS 17+**. System animated artwork requires the animated build and
**iOS 26+**; iOS controls when it is displayed. Online lyrics, artwork, and metadata features
depend on their external providers. VYBE searches library metadata and saved lyrics on-device.

### Install

1. Download the `.ipa` asset for your chosen variant below.
2. Open it in [SideStore](https://sidestore.io/) or [AltStore Classic](https://altstore.io/)
   and follow that installer's signing instructions. These IPAs are unsigned.
3. Import music with **+**, the Files app, or **Wi-Fi Transfer**.

Free Apple ID installations normally need refreshing within seven days and are subject to
Apple's active-app limit. Use the same signing identity and app identifier when updating;
keep a backup of your original music files.

### What's included

- Native UI, artwork colours, and light/dark themes.
- Gapless scheduling, custom crossfades, an 8-band EQ, and Transition Studio.
- Offline VYBE search with multiple song references, artist aliases, and explicit filters.
- Synced lyrics, playlists, smart discovery, bookmarks, and listening stats.
- Wi-Fi Transfer, metadata/tag tools, artwork lookup, and BPM tools.

This is a beta. Report reproducible issues through the repository's issue forms and use
[the security policy](https://github.com/MeezaUni/Erhu-iOS/security/policy) for vulnerabilities.
The source archives, GPLv3 text, third-party notices, and checksums accompany the IPAs.
