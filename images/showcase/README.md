# README showcase images

Upload the finished images to this folder (`images/showcase/`) with exactly the filenames
below. The main [README](../../README.md) already points at them, so each one appears as soon
as it is uploaded. Until then its slot shows as a broken image.

Take each screenshot on your iPhone, then style it to match the
[Android README](https://github.com/lochanpthakke/erhu#screenshots): the phone shown in a device
frame on a clean background. Use the same frame, background and scale for every image so the
tables line up.

Tips for capturing:

- Play real music with good artwork before capturing, so covers, colours and lyrics fill the screen.
- Hide personal details (notifications, other apps, your Apple ID).
- PNG, portrait. Keep the original resolution; GitHub scales the images down.
- The **Built with** column says which IPA to use. Use the animated build only where it is required.
