4Listen away from home (optional)

At home, Erhu uses the address above. To stream and download anywhere, Erhu Server gives this computer a permanent web address through Tailscale Funnel (free). Your iPhone needs nothing extra, and nothing changes on your router.

Press the button and Erhu Server does the rest: it installs Tailscale on this computer if needed, then opens a page whenever you have to do something (click through the installer, sign in once, allow once).

The address can be reached from the internet and is protected by your Erhu Server password, so keep that password strong and don't use it anywhere else.

Smaller streams away from home

With ffmpeg (free) on this computer, Erhu streams smaller MP3 copies away from home, so songs start sooner and use less data. At home it still plays your original files.

On: ffmpeg found.

Install ffmpeg yourself, then press Restart server: on a Mac with Homebrew run brew install ffmpeg; on Windows run winget install Gyan.FFmpeg.Essentials.

Installing ffmpeg… this can take a few minutes. Erhu Server restarts by itself when it's done.

Options

Keep this computer on and awake while you listen. If Windows asks whether to allow navidrome on the network, choose Allow for private networks.

Erhu Server runs Navidrome, an open-source music server (GPL-3.0), unmodified. Thank you to the Navidrome authors and contributors. Erhu Server's own source code is at github.com/MeezaUni/Erhu-iOS (GPL-3.0).
